# Arik's Portfolio

A professional, minimalist personal portfolio for web designers and developers. Built with React, Vite, and Tailwind CSS, featuring smooth animations and a modern dark aesthetic.

## 🚀 Features

- **Hero Section:** Engaging introduction with a minimalist design.
- **About:** Insight into professional background and philosophy.
- **Services:** Detailed overview of offerings (Design, Development, SEO).
- **Works:** Showcase of featured projects.
- **Blog:** Latest insights and articles.
- **Responsive Design:** Fully optimized for all device sizes.
- **Smooth Animations:** Powered by Framer Motion for a premium feel.

## 🛠️ Tech Stack

- **Framework:** React 19
- **Build Tool:** Vite
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Language:** TypeScript

## 📦 Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## 🌐 Live Demo & Preview

To see a live demo of the project locally:

1. Build the project:
   ```bash
   npm run build
   ```

2. Preview the production build:
   ```bash
   npm run preview
   ```

By default, the preview will be available at `http://localhost:4173`.

## 🎨 Customization

You can customize the content by editing the components in `src/components/`. The theme colors and fonts are configured in `src/index.css` and `tailwind.config.js` (if applicable) or directly via Tailwind classes in the components.
